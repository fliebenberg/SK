### App Shell & Theming

- [x] `UI-1` **A toggled control that gains a shadow remounts instead of re-rendering.** NativeWind's `shadow-*` and `scale-*` utilities are backed by CSS variables, and `react-native-css-interop` "upgrades" a component the first time a matched rule declares one — wrapping it in a variable provider, which changes its element type and so unmounts and remounts it. Any `isActive ? '… shadow-sm' : '…'` className hit this on every selection change. Resolved 2026-08-25. It surfaced as a theme switch red-screening, because the dev-only warning printer deep-walked the component's props with `JSON.stringify`, reached React Navigation's `NavigationStateContext` default value through the owner fibers, and enumerating it fired a getter that throws "Couldn't find a navigation context" — so the warning that would have named the component killed the render instead. Three fixes: [patches/react-native-css-interop+0.2.4.patch](file:///c:/Fred/Coding/SK/expo-app/patches/react-native-css-interop+0.2.4.patch) now summarises props one level deep, so an upgrade warning can never crash again; the inactive branch of every affected toggle declares `shadow-none` (and `scale-100` where the selected state scales) so the variable exists from the first render — [SegmentedControl](file:///c:/Fred/Coding/SK/expo-app/components/SegmentedControl.tsx), the follow button in [teams.tsx](file:///c:/Fred/Coding/SK/expo-app/app/(tabs)/teams.tsx), the list/pitch switch in [TeamRosterPanel.tsx](file:///c:/Fred/Coding/SK/expo-app/components/sports/shared/TeamRosterPanel.tsx) and the four colour-swatch grids in [admin/[orgId]/settings.tsx](file:///c:/Fred/Coding/SK/expo-app/app/admin/%5BorgId%5D/settings.tsx); and a sweep of every conditional className in `expo-app` confirmed no other pair is asymmetric in a variable-backed utility (shadow, scale, rotate, skew, translate, ring, blur, gradient). **Watch for this when writing new selected/unselected styles**: whatever the selected state adds, the unselected state needs the neutral form of, not nothing.
